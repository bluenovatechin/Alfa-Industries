## 💻 How to Use in Your Application

### Browser / Vanilla HTML:
```html
<script src="alfa_hardware_data.js"></script>
<script>
  // Access verbatim pages dictionary
  console.log(window.alfaHardwareData.pages['company-profile.html']);
  console.log(window.alfaHardwareData.pages['quality.html']);

  // Access products
  const product = AlfaHardwareAPI.getProductByCode('AFS-01');
  console.log(product.title, product.specifications, product.images.fullLocal);
</script>
```

### React / Next.js / Vite (ESM):
```javascript
import { alfaHardwareData, AlfaHardwareAPI } from './alfa_hardware_data.js';

// Get verbatim company info
const company = AlfaHardwareAPI.getCompanyInfo();
console.log(company.aboutUs.text);
console.log(company.infrastructure.text);

// Get page by filename
const indexPage = AlfaHardwareAPI.getPage('index.html');
const heroSliders = indexPage.sections.find(s => s.sectionId === 'slider').slides;
```

### Node.js / Express (CommonJS or JSON):
```javascript
const { alfaHardwareData, AlfaHardwareAPI } = require('./alfa_hardware_data.js');
// OR
const data = require('./alfa_hardware_data.json');
```
